Tentang Aplikasi

KosKu Mobile adalah aplikasi pencatat keuangan dan kehidupan kos harian. Dibuat untuk membantu mengelola keuangan pribadi dengan fitur lengkap meliputi:

Pencatatan pemasukan & pengeluaran
Dashboard dengan grafik visual
Catatan kehidupan kos kolaboratif
Mode admin & pengamat
Export data ke Excel
Penyimpanan cloud real-time
